# code_lab_IGNIX

Repositorio personal utilizado como espacio de práctica y experimentación en programación.

Aquí se recopilan scripts, algoritmos, soluciones de problemas, pruebas técnicas y pequeños proyectos desarrollados durante el aprendizaje y la práctica diaria. El objetivo es mantener un entorno organizado donde almacenar código de distintas tecnologías, lenguajes y plataformas como Acepta el Reto.
